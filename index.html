First-time setup
  1. Create a Spotify app in the Spotify Developer Dashboard.
  2. Add this page’s URL as a Redirect URI in the app settings.
  3. Paste the app’s Client ID above and connect.
Playback through Spotify’s API requires Spotify Premium and an active Spotify playback device.
